## О проекте

**`Schutz-Kaput`** (`ks_patcher.py`) — модульный инструмент на чистом **Python 3** (без единой внешней зависимости `pip`) с полноэкранным оконным интерфейсом **`ncurses`-стиля (TUI)** и командной строкой (**CLI**) для подготовки прошивок ЭБУ VAG:

- перевод защиты компонентов в пассивный режим (**`KS_PASSIVE`**) без износа `NvM` на неродном автомобиле;
- офлайн-активация всех штатных функций **`FeC` / `SWaP`** с корректным заводским статусом в диагностике `ODIS`;
- прямая распаковка и сборка дилерских контейнеров **`.frf` / `.odx-f` / `.odx`** со встроенным ключом расшифровки `frf.key`;
- **100% обратимость (`--restore-stock`)** — побитовый возврат всех пропатченных участков в заводской сток.

## Быстрый старт

Требуется только стандартный **Python `3.9+`** (macOS / Linux / Windows). Сторонние пакеты устанавливать не нужно.

### Интерактивный режим (рекомендуется)

```bash
python3 ks_patcher.py
```

Горячие клавиши в TUI:
- `↑` / `↓`, `Enter`, `Пробел` — навигация и переключение чекбоксов;
- `L` — мгновенное переключение языка интерфейса (`Русский` ⇄ `English`);
- `D` — показать / скрыть технические подробности (адреса в `CodeFlash`, `CRC-32`, `SHA-256`, байты патчей);
- `A` — информация об авторе и условия использования.

### Основные команды CLI

```bash
# 1. Вывести таблицу всех поддерживаемых модулей ЭБУ
python3 ks_patcher.py --list-targets

# 2. Проверить заводской контейнер (.frf / .odx-f) или бинарный дамп (.bin)
python3 ks_patcher.py -t <target> inspect <firmware.frf|dump.bin>

# 3. Пропатчить прошивку и собрать пакет под ODIS-E (если поддерживается модулем)
python3 ks_patcher.py -t <target> patch <firmware.frf> --build-odx ./ODIS_READY

# 4. Пропатчить сырой бинарный дамп для программатора на столе
python3 ks_patcher.py -t <target> patch <dump.bin> -o <patched.bin>

# 5. Побитово откатить ранее пропатченный дамп обратно в 100% заводской сток
python3 ks_patcher.py -t <target> patch <patched.bin> --restore-stock -o <restored.bin>

# 6. Распаковать заводской .frf или .odx-f на отдельные блоки данных
python3 ks_patcher.py -t <target> unpack <firmware.frf> -o ./unpacked --skip-large

# 7. Запустить встроенные самотесты сигнатур, кодеков и побитового отката
python3 ks_patcher.py selftest
```

*(Готовые примеры под конкретный блок и инструкция по прошивке — в документации выбранного таргета из таблицы выше.)*

## Архитектура проекта

Каждый поддерживаемый ЭБУ изолирован в собственном плагине внутри `targets/<module>/` со своей документацией, поэтому добавление новых блоков не затрагивает ядро и интерфейс:

```text
.
├── ks_patcher.py          # Точка входа (интерактивный TUI + CLI)
├── LICENSE.md             # Некоммерческая лицензия Right-to-Repair и отказ от ответственности (EN / RU)
├── core/
│   ├── i18n.py            # Локализация RU/EN, ANSI-стили, предупреждения
│   ├── pattern.py         # Поиск сигнатур с масками и проверка выравнивания
│   ├── containers.py      # Парсер/сборщик FRF, ODX, PDX и кодек LZSS A0
│   └── target_base.py     # Базовый интерфейс плагина ЭБУ (EcuTargetPlugin)
├── tui/
│   ├── screen.py          # Терминальный движок (?1049h, raw input, SIGWINCH)
│   ├── widgets.py         # Оконные виджеты, меню, чекбоксы, выбор файлов
│   └── app.py             # Контроллер пользовательских сценариев TUI
└── targets/
    └── mfk3/              # Таргет 0x00A5 Valeo MFK3 (2Q0 980 653, RH850)
        ├── README.md      # Документация и инструкция по прошивке MFK3 (RU)
        ├── README.en.md   # Документация и инструкция по прошивке MFK3 (EN)
        ├── constants.py   # Карта памяти, размеры дампов и таблица 9 кодов FeC
        ├── signatures.py  # Машинные сигнатуры RH850 и правила патчей/отката
        ├── loader.py      # Автораспознавание FRF / ODX / DB_01 / полных дампов
        └── plugin.py      # Логика инспекции, патчинга, ODX-сборки и самотестов
```
